## v1.0.0 の機能
- **基盤**：PWA（ホーム画面に追加・オフライン起動）、端末内の保存（IndexedDB）、共通項目の自動付与、変更履歴、ゴミ箱と復元、入力チェック、JSONバックアップ／復元（全部成功するか何も変わらない）、引継ぎ情報、自動テスト画面
- **プロジェクト管理**：ホームのカード（完成度・次にやること・未解決・要望）、検索と絞り込み、作成・編集・複製・関連データごとの削除/復元/完全削除、次にやること、未解決事項
- **仕様書**：Version管理（変更案→差分確認→確定）、確定Versionの保護、差分表示、要望箱からの反映、Factory移行用指示書（17項目）
- **3AI**：ChatGPT・Claude・Gemini への依頼文作成（自動送信なし）、個人情報チェック（匿名化してコピー）、回答の保存と比較（採用・保留・不採用）、採用案→要望箱、次のおすすめAI
- **コード／ファイル・URL**：ファイルとVersionの管理、URL要約の記録
- **テスト・完成度・引継ぎ**：テスト管理（不合格→修正→再テストの履歴）、共通テスト16項目、完成度8項目の自動連動、完成の厳格な条件、実機確認・公開確認、プロジェクト別／Factory全体の引継ぎ、v1完成判定画面
- **7プロジェクト**：正式初期登録（Factory本体＋7件）、既存アプリ取込の流れ
- **同期（Firebase Auth＋Firestore・無料のSparkプラン）**：Googleログイン（ポップアップ方式）、初回正本登録・取り込み（初回セットアップ・災害復旧用）、PC・iPhoneの双方向同期（ボタンを押したときだけ・記録ごとの差分・送る前/受け取る前に件数と内容を表示・競合は利用者が選ぶ）、半自動のお知らせ（受け取り待ち・未送信の表示だけ）
- **実機確認の記録**：同じ端末の記録を1項目で判定、未記入の重複は「重複として整理」（削除しない）、名前が違う同じ端末は利用者の確認で「同じ端末としてまとめる」（削除・変更しない・解除できる）
- **デザイン**：Design-1「工房の工程票」（ライト・ダーク、iPhone SE〜PC）

## 守っている安全対策（v1.0.0 で変更なし）
- 端末内（IndexedDB）が正本。オフラインでも全機能が使える
- クラウドのデータは削除しない（削除の命令を持たない・Security Rules でも削除禁止）。確認なしの全件上書きをしない
- 送る・受け取るは、件数と内容を確認してボタンを押したときだけ。受け取る前に端末内の控えを自動で作り、照合が合わなければ控えへ戻す
- バックアップ／復元・取り込みは「全部成功するか、何も変わらないか」
- 削除はほかの端末へ反映しない。端末ごとの記録・この端末だけの記録・ゴミ箱は同期しない
- 個人情報（児童・生徒・学校の実データ）を3AIへ自動で送らない。有料APIを使わない
- 自動テストは本番のデータ（factory・factory-sync）を変更しない

## 既知の制限
- 削除はほかの端末に反映しない（この端末で削除した記録は、ほかの端末とクラウドには残る）
- 自動同期はない（送る・受け取るはボタン。お知らせは表示だけ）。競合は常に利用者が選ぶ
- 「クラウドの最新を確認」はクラウドの全件（約400件）を読む（無料枠の範囲。1日に何十回も押すと読み取り数が増える）
- 1回の送信は150件ずつ。大きい記録（分割される記録）を一度に多数送ると、Firestoreの1回の上限に近づくことがある（通常の編集では起きにくい）
- iPhoneはホーム画面に追加して使う（追加しないと、長期間使わない場合にデータが消えることがある）。定期的なバックアップを推奨
- ログイン・同期には www.gstatic.com（Firebase公式配布元）への接続が必要
- 更新直後の1〜2回の表示は前の版のことがある（2〜3回再読み込みで新しい版）
- 個人情報チェックは自動判定のため完全ではない（最後は目で確認）。URLのタイトル取得は多くのサイトでできない（回避処理はしない）
- 差分は行単位。仕様書本文は整形せずに表示。保存するファイル名は英数字
- 開発環境では本物のFirebaseで自動テストできない（同じ形の「にせFirebase」で確認し、本物は実機で確認済み）
- v0.11.6以前の自動テストが本番の同期の記録に書き込んだ控えは残っている（同期への影響なし・削除していない）
