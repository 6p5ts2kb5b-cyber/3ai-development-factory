# Factory のデザイン（v0.11.0〜）「工房の工程票」

## 考え方
- Factoryは「やりたいことを、3つのAIと一緒にアプリへ仕上げていく工房」。画面は工房の**工程票（現品票）を並べた作業板**として作る
- プロジェクト＝工程票。**次にやること＝安全黄のテープ**（いちばん大事な情報なので、黄色はここと選択中の印だけに使う）
- 完成度・件数＝工場の表示板の数字（DIN系の数字書体）
- 3つのAI＝信号灯（左上のロゴ・アイコンの3つの丸）
- 目立たせるのは1か所（次にやること）。ほかは静かに、罫線と余白で整える

## 書体（外部フォントは読み込まない：通信しない・オフラインでも同じ）
- 本文：Windows＝BIZ UDPゴシック、iPhone・Mac＝ヒラギノ角ゴ
- 数字：iPhone・Mac＝DIN Alternate、Windows＝Bahnschrift

## 形
- 角の丸み：大きい面12px・内側の部品8px・状態の札5px（荷札のような四角）・絞り込みは丸
- タブ：下線式（選択中は墨の太線）。下のメニュー：選択中は上に安全黄の印。PCの左メニュー：左に安全黄の印
- ボタンの高さ：44px以上（主な操作は48px以上）
- 動き：シートが下から出る・ボタンを押すと少し沈むだけ。「動きを減らす」設定では動かさない

## 守ること
- 見た目は css/style.css を入口に、Design-1のCSSパーツを順番に読み込む。画面の部品の名前（id・class）と文言は、自動テストが使うので変えない
- 機能・データ・同期は、デザインの変更で触らない
